snydrone shot planner

A language model turns a spoken shot description into JSON. This is everything that happens next: the JSON is validated and clamped, a subject-relative trajectory is generated from it, and the result is checked for flyability before anything reaches a flight controller. The same code runs here and on the aircraft.
